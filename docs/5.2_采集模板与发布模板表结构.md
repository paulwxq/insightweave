# 5.2 工作区、模板、采集运行与发布运行表结构

记录日期：2026-10-20。状态：**讨论稿；尚未修改代码或执行建表**。

本文承接 [5.1_数据源工作区采集运行与发布运行模型.md](5.1_数据源工作区采集运行与发布运行模型.md)，定义 `workspace_info`、`collection_template`、`publish_template`、`collection_run_info`、`collection_run_step`、`publish_run_info` 和 `publish_run_step` 七张目标表。先建立工作区与模板表，再建立采集运行和发布运行表。采集与发布模板是否合并仍在讨论，以下 SQL 暂沿用两张模板表的方案。

## 1. PostgreSQL 建表语句与字段注释

以下为 PostgreSQL 新库建表设计，**不是现有代码已实施的结构**。`workspace_id` 与两类模板 ID 使用各自的序列生成带前缀的短字符串，不从现有 UUID 转换。`updated_at` 在应用修改记录时更新；数据库默认值只负责插入时赋值。

```sql
CREATE SEQUENCE public.workspace_info_id_seq AS bigint START WITH 1;

CREATE TABLE public.workspace_info (
    workspace_id text PRIMARY KEY
        DEFAULT ('ws_' || nextval('public.workspace_info_id_seq')),
    source_id text NOT NULL,
    workspace_name text NOT NULL,
    workspace_desc text,
    created_by_user_id uuid,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT workspace_info_id_format
        CHECK (workspace_id ~ '^ws_[1-9][0-9]*$'),
    CONSTRAINT workspace_info_source_nonblank
        CHECK (length(btrim(source_id)) > 0),
    CONSTRAINT workspace_info_name_nonblank
        CHECK (length(btrim(workspace_name)) > 0),
    CONSTRAINT workspace_info_source_name_key
        UNIQUE (source_id, workspace_name)
);

ALTER SEQUENCE public.workspace_info_id_seq
    OWNED BY public.workspace_info.workspace_id;

COMMENT ON TABLE public.workspace_info IS
    '工作区：归属于一个数据源，隔离并复用该工作区内的采集产物；可先于运行创建';
COMMENT ON COLUMN public.workspace_info.workspace_id IS
    '工作区全局唯一短 ID，格式如 ws_1；由独立序列生成';
COMMENT ON COLUMN public.workspace_info.source_id IS
    '所属数据源 ID，如 db_src_1；未来也可引用其他类型的数据源';
COMMENT ON COLUMN public.workspace_info.workspace_name IS
    '工作区名称，同一数据源下唯一，如生产或测试';
COMMENT ON COLUMN public.workspace_info.workspace_desc IS '工作区用途说明';
COMMENT ON COLUMN public.workspace_info.created_by_user_id IS
    '创建人用户 UUID；当前没有用户身份时可为空';
COMMENT ON COLUMN public.workspace_info.created_at IS '工作区创建时间';
COMMENT ON COLUMN public.workspace_info.updated_at IS
    '工作区最后修改时间；修改名称或说明时同步更新';

CREATE SEQUENCE public.collection_template_id_seq AS bigint START WITH 1;

CREATE TABLE public.collection_template (
    collection_template_id text PRIMARY KEY
        DEFAULT ('coll_tmpl_' || nextval('public.collection_template_id_seq')),
    workspace_id text NOT NULL
        REFERENCES public.workspace_info (workspace_id),
    name text NOT NULL,
    description text,
    status text NOT NULL DEFAULT 'draft',
    steps text[] NOT NULL DEFAULT ARRAY[]::text[],
    step_config jsonb NOT NULL DEFAULT '{}'::jsonb,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT collection_template_workspace_name_key UNIQUE (workspace_id, name),
    CONSTRAINT collection_template_workspace_id_key
        UNIQUE (workspace_id, collection_template_id),
    CONSTRAINT collection_template_name_nonblank CHECK (length(btrim(name)) > 0),
    CONSTRAINT collection_template_status_check
        CHECK (status IN ('draft', 'active', 'disabled')),
    CONSTRAINT collection_template_active_steps_check
        CHECK (status <> 'active' OR cardinality(steps) > 0),
    CONSTRAINT collection_template_steps_check
        CHECK (steps <@ ARRAY['db', 'ddl', 'json', 'md', 'domain',
                              'dim_config', 'rel', 'sql']::text[]),
    CONSTRAINT collection_template_steps_no_null_check
        CHECK (array_position(steps, NULL) IS NULL),
    CONSTRAINT collection_template_step_config_object_check
        CHECK (jsonb_typeof(step_config) = 'object')
);

ALTER SEQUENCE public.collection_template_id_seq
    OWNED BY public.collection_template.collection_template_id;

COMMENT ON TABLE public.collection_template IS
    '采集模板：固定工作区内定时或手工采集的步骤集合及稳定运行参数；不保存采集产物';
COMMENT ON COLUMN public.collection_template.collection_template_id IS
    '采集模板短 ID，格式如 coll_tmpl_1；由独立序列生成';
COMMENT ON COLUMN public.collection_template.workspace_id IS
    '所属工作区 ID；通过工作区确定数据源及产物共享边界';
COMMENT ON COLUMN public.collection_template.name IS '同一工作区内唯一的模板名称';
COMMENT ON COLUMN public.collection_template.description IS '模板用途说明';
COMMENT ON COLUMN public.collection_template.status IS
    '模板状态：draft 草稿、active 启用、disabled 停用';
COMMENT ON COLUMN public.collection_template.steps IS
    '选中的采集步骤；执行前由后端按采集步骤依赖规则编排';
COMMENT ON COLUMN public.collection_template.step_config IS
    '按步骤名组织的固定运行参数 JSON 对象；仅存支持的参数，不存生成文件';
COMMENT ON COLUMN public.collection_template.created_at IS '模板创建时间';
COMMENT ON COLUMN public.collection_template.updated_at IS
    '模板最后修改时间；修改步骤或参数时同步更新';

CREATE SEQUENCE public.publish_template_id_seq AS bigint START WITH 1;

CREATE TABLE public.publish_template (
    publish_template_id text PRIMARY KEY
        DEFAULT ('pub_tmpl_' || nextval('public.publish_template_id_seq')),
    workspace_id text NOT NULL
        REFERENCES public.workspace_info (workspace_id),
    name text NOT NULL,
    description text,
    status text NOT NULL DEFAULT 'draft',
    steps text[] NOT NULL DEFAULT ARRAY[]::text[],
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT publish_template_workspace_name_key UNIQUE (workspace_id, name),
    CONSTRAINT publish_template_workspace_id_key
        UNIQUE (workspace_id, publish_template_id),
    CONSTRAINT publish_template_name_nonblank CHECK (length(btrim(name)) > 0),
    CONSTRAINT publish_template_status_check
        CHECK (status IN ('draft', 'active', 'disabled')),
    CONSTRAINT publish_template_active_steps_check
        CHECK (status <> 'active' OR cardinality(steps) > 0),
    CONSTRAINT publish_template_steps_check
        CHECK (steps <@ ARRAY['db', 'ddl', 'json', 'domain',
                              'table_schema', 'dim_value', 'rel', 'sql']::text[]),
    CONSTRAINT publish_template_steps_no_null_check
        CHECK (array_position(steps, NULL) IS NULL)
);

ALTER SEQUENCE public.publish_template_id_seq
    OWNED BY public.publish_template.publish_template_id;

COMMENT ON TABLE public.publish_template IS
    '发布模板：固定工作区内定时或手工发布的步骤集合；每次运行读取当时可用的采集产物';
COMMENT ON COLUMN public.publish_template.publish_template_id IS
    '发布模板短 ID，格式如 pub_tmpl_1；由独立序列生成';
COMMENT ON COLUMN public.publish_template.workspace_id IS
    '所属工作区 ID；发布运行只能读取该工作区的采集产物';
COMMENT ON COLUMN public.publish_template.name IS '同一工作区内唯一的模板名称';
COMMENT ON COLUMN public.publish_template.description IS '模板用途说明';
COMMENT ON COLUMN public.publish_template.status IS
    '模板状态：draft 草稿、active 启用、disabled 停用';
COMMENT ON COLUMN public.publish_template.steps IS
    '选中的发布步骤；数组排列不决定执行顺序，后端执行前按固定规则排序';
COMMENT ON COLUMN public.publish_template.created_at IS '模板创建时间';
COMMENT ON COLUMN public.publish_template.updated_at IS
    '模板最后修改时间；修改步骤集合时同步更新';

CREATE TABLE public.collection_run_info (
    collection_run_id uuid PRIMARY KEY,
    workspace_id text NOT NULL
        REFERENCES public.workspace_info (workspace_id),
    collection_template_id text,
    trigger_type text NOT NULL,
    status text NOT NULL DEFAULT 'pending',
    run_by_user_id uuid,
    message text,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT collection_run_info_workspace_id_key
        UNIQUE (workspace_id, collection_run_id),
    CONSTRAINT collection_run_info_workspace_template_fk
        FOREIGN KEY (workspace_id, collection_template_id)
        REFERENCES public.collection_template
            (workspace_id, collection_template_id),
    CONSTRAINT collection_run_info_trigger_type_check
        CHECK (trigger_type IN ('manual', 'scheduled')),
    CONSTRAINT collection_run_info_scheduled_template_check
        CHECK (trigger_type <> 'scheduled' OR collection_template_id IS NOT NULL),
    CONSTRAINT collection_run_info_status_check
        CHECK (status IN ('pending', 'running', 'success', 'failed'))
);

CREATE INDEX collection_run_info_workspace_created_idx
    ON public.collection_run_info (workspace_id, created_at DESC);

COMMENT ON TABLE public.collection_run_info IS
    '一次采集运行一行；本次选中的步骤及各步骤结果保存在 collection_run_step';
COMMENT ON COLUMN public.collection_run_info.collection_run_id IS
    '本次采集运行的 UUID；由执行入口生成，同一次运行的步骤共用此值';
COMMENT ON COLUMN public.collection_run_info.workspace_id IS
    '所属工作区 ID；数据源可通过 workspace_info 查询';
COMMENT ON COLUMN public.collection_run_info.collection_template_id IS
    '本次使用的采集模板 ID；手工运行可为空，定时运行必填且模板须属于同一工作区';
COMMENT ON COLUMN public.collection_run_info.trigger_type IS
    '触发方式：manual 手工、scheduled 定时';
COMMENT ON COLUMN public.collection_run_info.status IS
    '运行整体状态：pending 待执行、running 执行中、success 全部成功、failed 存在失败或阻断';
COMMENT ON COLUMN public.collection_run_info.run_by_user_id IS
    '手工运行的发起人 UUID；定时运行可为空';
COMMENT ON COLUMN public.collection_run_info.message IS
    '无法归到单个步骤的运行消息或失败原因；步骤消息写入 collection_run_step';
COMMENT ON COLUMN public.collection_run_info.created_at IS '运行记录创建时间';
COMMENT ON COLUMN public.collection_run_info.updated_at IS
    '运行状态最后变更时间；不等同于专门的完成时间';

CREATE TABLE public.collection_run_step (
    collection_run_id uuid NOT NULL
        REFERENCES public.collection_run_info (collection_run_id),
    step_name text NOT NULL,
    status text NOT NULL DEFAULT 'pending',
    step_config jsonb,
    message text,
    started_at timestamptz,
    finished_at timestamptz,
    CONSTRAINT collection_run_step_pkey
        PRIMARY KEY (collection_run_id, step_name),
    CONSTRAINT collection_run_step_name_check
        CHECK (step_name IN ('db', 'ddl', 'json', 'md', 'domain',
                            'dim_config', 'rel', 'sql')),
    CONSTRAINT collection_run_step_status_check
        CHECK (status IN ('pending', 'running', 'success', 'failed', 'blocked')),
    CONSTRAINT collection_run_step_config_object_check
        CHECK (step_config IS NULL OR jsonb_typeof(step_config) = 'object'),
    CONSTRAINT collection_run_step_time_order_check
        CHECK (started_at IS NULL OR finished_at IS NULL
               OR finished_at >= started_at)
);

COMMENT ON TABLE public.collection_run_step IS
    '采集运行中一个已选步骤的一行结果；未选中的步骤不建行';
COMMENT ON COLUMN public.collection_run_step.collection_run_id IS
    '所属采集运行 UUID；与 step_name 组成联合主键';
COMMENT ON COLUMN public.collection_run_step.step_name IS
    '本次选中的采集步骤名称';
COMMENT ON COLUMN public.collection_run_step.status IS
    '步骤状态：pending 待执行、running 执行中、success 成功、failed 失败、blocked 被本次上游失败阻断且未执行';
COMMENT ON COLUMN public.collection_run_step.step_config IS
    '本次实际采用的额外参数快照；无额外参数时为 NULL，不保存工作区生成文件';
COMMENT ON COLUMN public.collection_run_step.message IS
    '该步骤的执行结果、失败或阻断原因';
COMMENT ON COLUMN public.collection_run_step.started_at IS
    '步骤实际开始时间；未启动的步骤为 NULL';
COMMENT ON COLUMN public.collection_run_step.finished_at IS
    '步骤完成或被阻断的时间；待执行或执行中的步骤为 NULL';

CREATE TABLE public.publish_run_info (
    publish_run_id uuid PRIMARY KEY,
    workspace_id text NOT NULL
        REFERENCES public.workspace_info (workspace_id),
    context_collection_run_id uuid NOT NULL,

    status text NOT NULL DEFAULT 'pending',
    run_by_user_id uuid,
    message text,
    created_at timestamptz NOT NULL DEFAULT now(),

    CONSTRAINT publish_run_info_context_collection_fk
        FOREIGN KEY (workspace_id, context_collection_run_id)
        REFERENCES public.collection_run_info
            (workspace_id, collection_run_id),
    CONSTRAINT publish_run_info_workspace_template_fk
        FOREIGN KEY (workspace_id, publish_template_id)
        REFERENCES public.publish_template
            (workspace_id, publish_template_id),
    CONSTRAINT publish_run_info_trigger_type_check

CREATE INDEX publish_run_info_workspace_created_idx
    ON public.publish_run_info (workspace_id, created_at DESC);

COMMENT ON TABLE public.publish_run_info IS

    '本次使用的发布模板 ID；手工运行可为空，定时运行必填且模板须属于同一工作区';
COMMENT ON COLUMN public.publish_run_info.trigger_type IS
    '触发方式：manual 手工、scheduled 定时';

COMMENT ON COLUMN public.publish_run_info.run_by_user_id IS

COMMENT ON COLUMN public.publish_run_info.message IS
```

`workspace_info` 是工作区的独立身份记录，允许在尚无采集运行和产物时创建。`workspace_name` 在同一 `source_id` 下唯一；`created_by_user_id` 保持与现有数据源表一致的可空 UUID 类型。字段采用 `workspace_name`、`workspace_desc`、`created_at`、`updated_at` 拼写。工作区不增加环境类型、启停状态或“当前运行”字段，这些需求尚未确定。

`workspace_info.source_id` 暂不设置指向 `db_source_info` 的外键：目标 `source_id` 还可能是 `file_src_...` 等其他类型，而现有数据源删除流程允许保留作业和发布历史。创建工作区时应由服务层校验数据源存在及归属；删除数据源后工作区及运行记录如何保留或清理，需要随数据源删除规则一并确定。若将来要求数据库层强制保证跨类型数据源引用，应先设计统一的数据源主表。唯一约束 `(source_id, workspace_name)` 同时支持按 `source_id` 查询其工作区。

`source_id` 统一使用 PostgreSQL `text`，包括数据源主表、工作区表及其他引用该 ID 的目标列。`varchar(32)` 不会让实际 ID 更短，也没有必要以任意长度限制代替 ID 格式校验；各类数据源 ID 的主表应按其前缀和递增数字规则设置格式约束。工作区表目前仅校验 `source_id` 非空，其所属数据源类型与存在性由服务层校验。

两张模板表均以 `workspace_id` 外键归属工作区，不重复存储 `source_id`。`steps` 的步骤名白名单、启用时非空由数据库约束校验；**步骤不重复、`step_config` 只能包含已选步骤及其允许参数**由保存模板的服务层校验。只有在采集执行入口确实消费模板值时，才为相应步骤加入固定运行参数；工作区当前的 Domain 数据库描述按 [5.4_Domain采集步骤变更方案.md](5.4_Domain采集步骤变更方案.md) 从 YAML 读取，不放进 `step_config`。发布模板不设 `step_config`，也不建 `publish_template_step`；`domain`、`rel`、`dim_value` 文件属于工作区中的动态采集产物，不拷贝进模板。两个模板均不设 `step_order` 或 `revision`。

`collection_run_info` 每次执行仅写一行；执行入口生成一个 `collection_run_id`，并为本次选中的每个步骤在 `collection_run_step` 建一行。未选步骤不建行；因本次上游失败而未启动的已选步骤记为 `blocked`，其 `started_at` 为空。运行整体状态由步骤结果汇总并更新：全部选中步骤成功才记 `success`，存在失败或阻断则记 `failed`；编排层错误可写入运行表的 `message`。执行入口应以同一事务创建运行行与所有待执行的步骤行；实际步骤可分别提交结果。步骤执行前仍由后端按采集依赖规则编排，不从步骤表的插入顺序推断执行顺序。

`collection_run_info` 只保存运行级身份、触发信息和状态；`collection_run_step.step_config` 只保存本次实际使用的步骤参数，不保存 YAML 全量内容。`collection_template` 增加 `(workspace_id, collection_template_id)` 唯一约束，是为了用复合外键保证运行关联的模板属于同一工作区；模板 ID 本身仍是主键。定时运行必须使用模板，手工运行可不关联模板。当前方案不存储工作区的“最近步骤状态”副本；从运行步骤历史计算工作区当前状态及发布准入的规则仍需单独设计。采集运行与文件版本的精确关联也尚待设计。

`publish_run_info` 每次发布写一行，`publish_run_step` 为本次选中的每个发布步骤写一行；一次发布中部分步骤成功、部分步骤失败时，已成功提交的步骤结果不会被整体失败抹去。发布运行必须关联同一工作区中的一次 `context_collection_run_id`，表示创建本次发布所依据的采集运行；手工发布可由用户选择，定时发布选择哪次运行的规则尚待设计。该字段不是本次发布所有文件的唯一生产运行。发布步骤可能同时读取该工作区内不同采集运行留下的文件，因此 `input_manifest` 用于记录每步实际读取的产物及版本。该字段目前可空，元素格式、版本标识及文件保留规则尚待设计；在这些规则落地前，不能仅凭 `context_collection_run_id` 声称发布输入已可完整追溯。

`publish_template` 增加 `(workspace_id, publish_template_id)` 唯一约束，以便发布运行通过复合外键校验模板归属。定时发布必须关联模板，手工发布可不关联。若后续决定统一采集和发布模板，应同步调整两类运行的模板字段和外键；本节暂不预设合并结果。旧 `publish_info.is_current_publish` 表示按数据源、步骤确定的当前发布；目标发布范围尚未决定，因此上述两张新表暂不定义该字段或对应唯一索引。确定生产／测试工作区及发布目标的隔离规则后，仍须设计当前发布指针或等价约束，不能直接丢弃这项能力。

发布后端目前只对传入步骤校验并去重，尚未在执行前统一排序；前端虽按固定顺序提交，定时任务不能依赖前端。目标实现必须让后端只对**本次选中的发布步骤**排序并按统一顺序执行，不补入未选步骤；此待办亦记录于 [100_项目备忘录.md](100_项目备忘录.md)。目标是让每次发布运行记录本次实际读取的产物版本，模板持续用于发布最新的合格产物。
