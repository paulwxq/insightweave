## 关键证据

- 区分原始 HTTP、`ChatOpenAI`、现有工厂和实际 NL2SQL 角色。对默认、开启、关闭三组，记录最终发出的参数、请求与响应模型 ID、状态和错误码、请求 ID、推理字段位置及是否非空、推理 token 计数和正文格式。按 Doc 24 重复关键关闭组。若只有 SDK 消息无推理字段，回到 HTTP 层对照。对没有暴露模型身份、无法区分关闭与隐藏、服务降档或模型重路由的结果按 Doc 24 判定。
